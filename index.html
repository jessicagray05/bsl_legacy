Creative front-end concept

Turning hand movement into words made of stars.

This portfolio piece explores the idea of accessible interaction design. It uses a live camera, browser-based hand tracking and a space themed interface to create a visual response to simple hand gestures inspired by British Sign Language.

Project Aim

The idea behind this project is to present a more visual and engaging way to think about sign-based interaction. It is a concept demo rather than a full BSL translator, but it shows how gesture tracking, motion design and front-end development can work together.

About this project

Why I made it

I wanted something for my GitHub portfolio that felt more interesting than a basic static webpage. The space theme keeps the design clean while also making the interaction feel a bit more memorable. The star animation reacts to recognised hand shapes and forms a word on screen, which helps turn a technical demo into something more visual.

What it shows

What this demonstrates

This project shows front-end layout work, responsive design, webcam handling, real-time gesture logic, animation with canvas and a more thoughtful user experience. It is simple to use, but still feels like a proper project rather than a one page placeholder.

Notes

Important

This is not a full British Sign Language recognition system. BSL is a complete language with grammar, movement, facial expression and context, so a real translator would need a much more advanced model and much more training data. This project is a creative prototype showing the idea in a clean way.
